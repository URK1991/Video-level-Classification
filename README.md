**File Structure**

  - Data folder contains the file _create_pikle.py_ that creates the pickle file of your data (features extracted from a pre-trained model)
  - Both the models [LSTM and Transformer] can be founds in the models folder
  - Training script _Train.py_ along with the loss functions and the data transforms can be found in the utils folder

**Related Works**

  - The use of CNN-LSTM is presented in a study currently under review.
  -  The transformer-based model is presented at the International Ultrasonics Symposium (IUS-2024) in Taipei
